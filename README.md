# 需求对接工具（Need Match）

一个零依赖、免注册的需求对接网页工具。打开即用，发布需求与需求对接时均自动生成随机用户名，保护隐私、降低使用门槛。

## 功能特性

- **免注册**：无需账号密码，打开网页即可使用。
- **随机用户名**：每次发布需求或认领需求时，系统自动生成随机用户名（可手动更换）。
- **发布需求**：填写标题、类型、描述、联系方式即可发布。
- **需求大厅**：卡片式浏览所有需求，支持按类型筛选和关键词搜索。
- **需求对接**：对感兴趣的需求发起对接，留下随机用户名与联系方式。
- **我的记录**：区分"我发布的"与"我对接的"，本地保存。
- **本地持久化**：数据保存在浏览器 localStorage，刷新不丢失。
- **示例数据**：首次打开自动载入 14 条贴合科技、金融、融资场景的示例需求（AI 大模型、GPU 算力、SaaS 渠道、FinTech 融资、IPO 财务顾问、供应链金融、股权设计、产业资本、区块链跨境支付等），并含若干对接记录；"我发布的""我对接的"标签也有演示内容。页脚可"重新载入示例"或"清空全部数据"。

## 使用方式

直接用浏览器打开 `index.html` 即可。或用任意静态服务器托管，例如：

```bash
python -m http.server 8000
```

然后访问 `http://localhost:8000`。

## 功能冒烟测试

仓库附带 `test_smoke.js`，使用 jsdom 模拟真实浏览器操作，覆盖示例数据载入、我发布的/我对接的、发布、对接、持久化、筛选搜索、重新载入、清空、XSS 防护等 35 项检查。运行方式：

```bash
npm install jsdom          # 首次需准备 jsdom 环境
node test_smoke.js
```

## 说明

数据存储在当前浏览器中，不同浏览器/设备之间不共享。这是纯前端设计，简单易用、无需后端。
