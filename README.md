# 需求对接工具（Need Match）

一个免注册、云端共享的需求对接网页工具。发布需求与对接时均自动生成随机用户名，保护隐私、降低使用门槛。所有访客共享同一份云端需求池。

## 功能特性

- **免注册**：无需账号密码，打开网页即可使用。
- **随机用户名**：每次发布需求或发起对接时自动生成随机用户名（可手动更换）。
- **云端共享**：需求与对接记录存于云数据库，所有访客实时看到同一份需求池；刷新、换设备不丢失。
- **发布需求**：填写标题、类型、描述、联系方式即可发布到云端。
- **需求大厅**：卡片式浏览所有需求，支持按类型筛选和关键词搜索。
- **需求对接**：对感兴趣的需求发起对接，留下随机用户名与联系方式，需求方可见。
- **我的记录**：通过本地 client_id 区分"我发布的"与"我对接的"（仅作界面标识，非安全边界）。
- **示例数据**：云端预置 14 条贴合科技、金融、融资场景的示例需求（AI 大模型、GPU 算力、SaaS 渠道、FinTech 融资、IPO 财务顾问、供应链金融、股权设计、产业资本、区块链跨境支付等）。
- **失败降级**：云端不可用时显示明确错误与重试入口，不会静默展示空数据。

## 技术架构

- 纯前端单文件 `index.html`（零构建），通过 CDN 引入 `@tencent-ai/workbuddy-cloud-sdk`。
- 数据存于 WorkBuddy 云数据库 `public.needs` 表，字段：`id / title / cat / description / contact / publisher / client_id / status / created_at / matches(JSONB)`。
- 访问策略为"公开读写"的访客留言板模式（RLS 放行 anon/authenticated 的增删查改），契合免注册定位。
- 随机用户名与 client_id 保存在浏览器 localStorage，仅用于身份展示与"我的"筛选。

## 使用方式

线上访问（推荐，云端共享生效）：通过已发布的应用链接打开。

本地调试：`python -m http.server 8000` 后访问 `http://localhost:8000`。
注意：云端 SDK 的公钥绑定发布域名 Origin，本地 localhost 环境可能无法连接云端；本地运行主要用于 UI 调试，完整功能以线上链接为准。

## 功能冒烟测试

`test_smoke.js` 使用 jsdom + 内存版云数据库 mock，覆盖首屏加载、发布、对接、我发布的/我对接的、删除、筛选搜索、失败降级等 19 项检查：

```bash
npm install jsdom          # 首次需准备 jsdom 环境
node test_smoke.js
```

## 说明

这是一个免注册的公开需求板：任何访客都能查看、发布、对接和删除需求。`client_id` 只是浏览器本地生成的随机标识，不具备鉴权能力；请勿填入高度敏感的个人信息。
